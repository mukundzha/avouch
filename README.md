# Scrut

> Review first. Commit second.

Scrut is a lightweight local code review tool that helps developers catch issues in their changes before they reach a pull request.

The goal is simple: review your code before anyone else has to.

## Current Progress

- Detect Git repositories
- Detect changed files
- Parse Python code
- Add code review rules

## Roadmap

- Generate useful feedback
- Build a developer-friendly review workflow

## Development

```bash
git clone https://github.com/mukundzha/scrut.git
cd scrut

pip install -e 
```
