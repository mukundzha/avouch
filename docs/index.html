I was paying for a reviewer that spent half its report on code I never wrote.

It queued my actual diffs behind everyone else's. I wanted a reviewer that only looks at the code I'm about to push, runs locally in the seconds before git push, and costs nothing. So I built one.

The report is the diff

Every finding is attributable to work you are about to push — never the legacy you inherited. Old debt never reaches your screen.

First run, clean

avouch init measures your real code — params, nesting, complexity — and writes an avouch.toml your repository already passes.

Actually local

No daemon, no cloud, no file sent anywhere. Python 3.10+ and git — that's the whole install.

Future findings only

Baseline snapshots make later runs show nothing but what changed since the snapshot. Suppression is history, not silence.

17 AST rules

Parameters, nesting, complexity, bare excepts, duplicate branches, mutable defaults — each one explainable, each one configurable.

CI-native

--json emits a stable, versioned document. Exit codes 0 clean · 1 findings · 2 error.
